规财务书写规范说明

人民币大写用于票据、合同、记账凭证，须严格使用正楷或行书书写，不得使用简体或错字。

标准用字

数字：零、壹、贰、叁、肆、伍、陆、柒、捌、玖
数位：拾、佰、仟、万、亿
单位：元（不可写「圆/园」）、角、分、整（或正）

关键规则

  • 整数金额末尾加「整」，如 100 → 壹佰元整
  • 有角无分可加「整」，有分不加「整」，如 123.45 → 壹佰贰拾叁元肆角伍分
  • 角位为 0 而分位不为 0 时补「零」，如 10.05 → 壹拾元零伍分
  • 连续零合并为单个「零」，杜绝「零零」等不规范写法
  • 禁止简体：一、二、三、十 等须写作 壹、贰、叁、拾

示例对照

  • 10086.5 → 人民币壹万零捌拾陆元伍角整
  • 0 → 人民币零元整
  • 2000000 → 人民币贰佰万元整
